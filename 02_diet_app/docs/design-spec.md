# Matsumoto Diet App — Design / Requirements Spec

## 0. このドキュメントの目的

「あすけん」を参考に、松本さん専用に作るダイエット/食事記録アプリの **機能要件** と **UI設計** をまとめたものです。実装担当（私）と Claude Designer の間で UI 仕様の共通理解を持つために用意しました。

> ⚠️ 著作権上の注意：あすけんの UI スクリーンショット・キャラクター・文言を直接コピーすることは避け、機能コンセプトのみを参考に独自の UI・キャラクター・文言で実装します。

## 1. プロダクト概要

| 項目 | 内容 |
|------|------|
| 名称（仮） | **Karute（カルテ）** ／ サブタイトル「あなたの一日を栄養で記録する」 |
| ターゲット | 松本さん 1人（個人利用） |
| プラットフォーム | モバイル中心の Web アプリ（Next.js）。スマホブラウザでホーム画面に追加して使う想定 |
| ストレージ | LocalStorage（端末ローカル）。サーバ DB なし |
| AI バックエンド | Claude API（Anthropic SDK）を Next.js API Routes 経由で呼び出し |
| デザイン方向性 | クリーン × 親しみ。和の温度感を残しつつ、医療機関の「カルテ」のように"自分の身体記録"を扱う雰囲気 |

## 2. ユースケース（松本さんの一日）

1. **朝食後**：今日の朝食を素早く記録 → 残り摂取目安が分かる
2. **昼の通勤中**：体重と昨晩の振り返りを確認
3. **会社のランチ前**：写真を撮るだけで AI が自動で食事推定 → ワンタップで記録
4. **夕方のジム前**：今日の AI 筋トレメニュー（Karute Coach）を開いてその日のセットを実行
5. **夜寝る前**：今日の総評（AI 栄養士からのコメント）を読み、明日の予定食事を入力

## 3. コア機能要件

### 3.1 食事記録（Meal Log）

- 4区分：**朝食 / 昼食 / 夕食 / 間食**
- 食品の追加方法（実装優先順）：
  1. **検索** — 内蔵食品 DB から名前で検索（ひらがな部分一致）
  2. **AI 写真解析** — カメラで撮影 → Claude vision で品目と推定量を抽出
  3. **AI フリーテキスト** — 「コンビニのおにぎり2個と味噌汁」のような口語文から複数品目を構造化
  4. **マイ食品** — よく食べるものを保存
- 食品ごとの保持データ：
  - 名前、量（g または個数）、エネルギー(kcal)、PFC（タンパク質/脂質/炭水化物）、食物繊維、塩分、糖質、カルシウム、鉄、ビタミン A/B1/B2/C/D/E

### 3.2 栄養可視化（Nutrition Stats）

- ダッシュボードに **大きな円形メーター**（今日の摂取 kcal / 目標 kcal）
- **PFC バー** — 3色の積み上げで一日の P/F/C 比を表示
- **14栄養素バー一覧** — 不足/適切/過剰 の3段階を色で表現
- 達成スコア（0〜100点）：摂取バランスから自動算出して表示

### 3.3 体重・体脂肪トラッキング

- 日次入力（体重、体脂肪率、メモ）
- 30日折れ線グラフ
- 目標体重への到達予測（直近2週間の傾きから単純線形回帰）

### 3.4 運動記録（Exercise Log）

- カテゴリ：有酸素 / 筋トレ / ストレッチ / その他
- 種目・時間・推定消費 kcal
- 純摂取（摂取 − 消費）を栄養可視化に反映

### 3.5 目標設定（Profile / Goals）

- 身長、体重、年齢、性別、活動レベル
- 目標体重、目標達成日
- 目的コース：「ダイエット」「筋力アップ」「体型維持」「低糖質」
- 目的コースで栄養素の目標値（PFC比 / 個別栄養素）が自動切替

## 4. AI 機能要件

### 4.1 AI 栄養士キャラクター "**ハル先生（Karute Coach: Haru）**"

- 独自キャラクター。あすけんの「未来さん」「Miki」とは別人格。
- ペルソナ：30代・元アスリート出身の管理栄養士。語り口は丁寧だが少しだけ砕けた、励まし系。
- 対話モダリティ：
  - **デイリー総評** — 1日終わりに1食ごとに簡単コメント＋総合アドバイス
  - **チャット** — 自由質問（"プロテインって今夜飲んだ方がいい？" など）
  - **筋トレプラン生成（後述）**

### 4.2 写真からの食事認識

- カメラ起動 → 撮影 → 画像を Claude vision に投げる
- 出力フォーマットを JSON に固定（品目名・推定量g・推定kcal・自信度）
- ユーザーがその場で量と品目を補正してから保存

### 4.3 ★ Karute Coach — AI 筋トレプラン（目玉機能）

> あすけんの有料機能「ボディメイクコース」に着想を得つつ、より能動的な **週次プラン生成** を AI で実装する。

- 入力：
  - 目的（増量 / 減量 / 維持 / 部位重点）
  - 週あたり実施日数（2〜6日）
  - 利用可能設備（自重 / ダンベル / ジムフルセット）
  - 苦手部位・故障歴（自由記述）
  - 直近の食事ログ（直近 7 日分の PFC 平均を一緒に渡す）
- 処理：Claude に上記をコンテキストとして与え、**週次の分割（プッシュ/プル/レッグ等）と、1日ごとの種目・セット・レップ・休憩・推奨タンパク質目安** を JSON で返させる
- 出力 UI：
  - 週カレンダー＋当日のセットチェックリスト
  - セットごとに完了チェックでログ蓄積
  - 翌週のプランは前週の達成度＋食事ログを踏まえて自動再生成（"進捗フィードバックループ"）

### 4.4 食事 → 栄養 → トレ計画 のループ

Karute の差別化ポイントとして、**食事ログとトレーニングプランを同じ AI コンテキスト**で扱う。たとえばタンパク質摂取が継続的に不足していたら、AI が自動で「今週は補給が足りていないので強度を 1 段下げます」と提案する。

## 5. 画面構成（Information Architecture）

ボトムタブ 5 つ：

```
┌──────────┬──────────┬──────────┬──────────┬──────────┐
│  ホーム  │   記録   │  プラン  │  チャット │  設定    │
│  (Home)  │  (Log)   │ (Coach)  │  (Talk)  │ (Profile) │
└──────────┴──────────┴──────────┴──────────┴──────────┘
```

### 5.1 ホーム（Home）

- ヘッダー：日付ピッカー（左右で前日/翌日）
- カード①：今日の総評（円形メーター・スコア・残り kcal）
- カード②：PFC バー
- カード③：14栄養素バーリスト（タップで詳細）
- カード④：体重ミニグラフ（直近2週間）
- カード⑤：今日のハル先生コメント（AI生成・3行程度）

### 5.2 記録（Log）

- タブ：食事 / 運動 / 体重
- 食事タブ：朝/昼/夕/間食 4 セクション。各セクション右上「＋」で追加モーダル
- 追加モーダル：上部にトグル `検索 / 写真 / AIで書く / マイ食品`

### 5.3 プラン（Coach / 筋トレ）

- タブ：今日 / 週間 / 履歴
- 「今日」：種目カードのチェックリスト。各カードに `target sets x reps`、`完了`ボタン、メモ
- 「週間」：曜日ごとの種目サマリー
- 「履歴」：完了率と週次フィードバック
- 右上「再生成」ボタン → 質問フォーム → Claude 再呼出

### 5.4 チャット（Talk）

- LINE 風 1on1 チャット UI（ハル先生）
- 直近ログを context として裏で渡す（ユーザーには見せない）

### 5.5 設定（Profile）

- 個人情報、目標、目的コース、API キー設定（個人利用なので）
- データのエクスポート / インポート（JSON）

## 6. デザインガイドライン（Designer 引き継ぎ用）

### カラー（提案）
- Primary `#2EB872`（くすみ緑 / 健康・自然）
- Accent `#F2994A`（朝食/間食用のオレンジ）
- Neutral `#1F2937` / `#6B7280` / `#F3F4F6`
- 警告 `#EB5757`、注意 `#F2C94C`、適切 `#27AE60`

### タイポグラフィ
- 日本語：`Noto Sans JP`、見出し semibold、本文 regular
- 数値：`Inter` の tabular-nums を使い、kcal 等の桁を揃える

### モーション
- 円形メーターは初回ロード時に 800ms で 0→現在値にイージング
- 食事追加完了時に PFC バーが軽くポップ（spring 250ms）

### レイアウト原則
- スマホ縦長前提（最大幅 480px に収める）
- ボトムタブは固定、カード式でスクロール
- カード角丸 16px、影は柔らかく(`0 6px 24px rgba(0,0,0,0.06)`)

### コンポーネント想定（Designer 側で清書してほしい）
- `NutritionRing`（円形メーター）
- `PFCBar`（3色積み上げ）
- `NutrientRow`（栄養素1項目 — 名前/数値/状態カラーバー）
- `MealCard` / `MealItem`
- `WorkoutSetCard`（チェックボックス付き）
- `ChatBubble`（ハル先生 / ユーザー の2バリアント）

## 7. データモデル（軽量）

```ts
type Profile = {
  name: string;
  height: number; weight: number; age: number;
  sex: 'male' | 'female';
  activity: 'low' | 'mid' | 'high';
  goal: 'diet' | 'muscle' | 'maintain' | 'lowcarb';
  targetWeight?: number;
  targetDate?: string;
}

type FoodItem = {
  id: string; name: string; per: number; unit: 'g' | 'piece';
  kcal: number; protein: number; fat: number; carb: number;
  fiber?: number; salt?: number; ...
}

type MealEntry = {
  id: string; dateISO: string;
  slot: 'breakfast' | 'lunch' | 'dinner' | 'snack';
  foodId: string; amount: number;
}

type WeightEntry = { dateISO: string; weight: number; bodyFat?: number; memo?: string; }

type ExerciseEntry = {
  id: string; dateISO: string;
  type: 'cardio' | 'strength' | 'stretch' | 'other';
  name: string; minutes?: number; sets?: { reps: number; weight?: number }[];
  kcal: number;
}

type WorkoutPlan = {
  weekStartISO: string;
  days: { dayIndex: number; focus: string; items: PlanItem[] }[];
  proteinTargetG: number;
  notesFromAI: string;
}
```
