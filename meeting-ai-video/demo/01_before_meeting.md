# デモ設計: 第1章「会議前」画面録画シナリオ

- **本編での位置**: 02:03 – 04:50（約167秒）
- **デモのゴール**: 「会議前の“探す・思い出す・並べる”を、AIへの依頼に置き換えられる」ことを見せる
- **使用ツール**: Microsoft 365 Copilot（Copilot Chat / Work グラウンディング有効の状態）
- **録画本数**: 4本（ステップごとに分けて録画し、編集で連結する）

> 機能名・画面配置はテナントの構成やライセンスによって異なる。
> 収録前に必ず本番アカウントでリハーサルし、想定どおりの出力が返るか確認すること。

---

## 0. 事前準備（収録の前日までに）

### デモ環境
- [ ] デモ専用テナント、またはダミーデータのみのアカウントを用意する（**実データは絶対に録画しない**）
- [ ] ダミーの会議シリーズを作成する: 例「新サービス立ち上げ 定例（毎週火曜 14:00）」
- [ ] 過去回（1週間前）の会議を実施済みにし、**文字起こしを残しておく**
- [ ] 関連するダミーのメールを2〜3通、Teamsチャットを1スレッド用意する
- [ ] ダミー資料を3つ用意する（意図的に紛らわしい名前にする）
  - `新サービス企画_最終.pptx`（3週間前・更新者: 田中）
  - `新サービス企画_最終_v2.pptx`（2週間前・更新者: 佐藤）
  - `新サービス企画_最終_修正.pptx`（**5日前・更新者: 佐藤 ← これが最新**）

### 録画設定
- [ ] 解像度 1920x1080 / 30fps / マウスカーソル表示ON
- [ ] 表示スケール 125〜150%（本編で文字が読めるサイズにする）
- [ ] 通知をオフ（集中モード）、ブックマークバーと個人情報を非表示
- [ ] ブラウザは新規プロファイル、余計なタブは閉じる
- [ ] 音声は録らない（ナレーションは後乗せ）

## 1. ステップ1: 前回会議の決定事項を確認する（約45秒）

### 操作手順
1. Copilot Chat を開く（開いた状態から録画を始めてもよい）
2. 入力欄に下記プロンプトを貼り付ける（**タイプする様子も5秒ほど見せる**）
3. 送信し、回答が出るまでを録画する

### 入力プロンプト
```
先週の「新サービス立ち上げ 定例」で決まったことを教えてください。
次の形式でお願いします。
1. 決定事項（箇条書き・3〜5項目）
2. 保留になったこと
3. 前回のToDoと担当者
それぞれ、どの会議・どのファイルを根拠にしたか併記してください。
```

### 期待される出力（デモで見せたい形）
- 決定事項が3〜5項目の箇条書きで返る
- 「保留」「ToDo（担当者付き）」がセクション分けされている
- 参照元（会議名・ファイル名）へのリンクが表示される

### ナレーション
> 探しに行くのではなく、聞く。これが会議前のいちばん大きな違いです。
> 出典のリンクも一緒に返ってくるので、元の資料もすぐ開けます。

### 編集メモ
- 生成中のスピナーは1.5倍速で圧縮する
- 出力の「決定事項」部分にズームイン（1.3倍）＋黄色のハイライト矩形
- 参照元リンクの部分にマウスカーソルを重ねる動きを見せる

---

## 2. ステップ2: 散らばった情報を横断でまとめる（約45秒）

### 操作手順
1. 同じスレッドで続けて質問する（**会話が続いていることを見せるのがポイント**）
2. 回答が出るまでを録画する

### 入力プロンプト
```
このプロジェクトについて、直近2週間のメール・Teamsのチャット・ファイルの更新を
横断して確認し、会議前に知っておくべき動きを5つにまとめてください。
それぞれ「何が起きたか」「情報源（メール／チャット／ファイル）」「日付」を書いてください。
```

### 期待される出力
- メール・チャット・ファイルの3種類が混在した5項目のリスト
- 各項目に日付と情報源が付いている

### ナレーション
> Teams、メール、ファイル。人間なら3か所を開いて探すところを、依頼は1回です。
> ここが、検索とAIの違いです。

### 編集メモ
- 出力の「情報源」列が3種類バラバラであることが伝わるよう、3か所に矢印アノテーションを付ける
- 画面全体を一度引きで見せてから、リストへズームする

---

## 3. ステップ3: 最新版の資料を特定する（約32秒）

### 操作手順
1. 続けて質問する
2. 回答後、示されたファイルをクリックして開き、**更新日が一致していること**を1〜2秒見せる

### 入力プロンプト
```
「新サービス企画」という名前のファイルが複数あります。
今日の会議で使うべき最新版はどれですか。
最終更新日と最終更新者を根拠として示してください。
```

### 期待される出力
- `新サービス企画_最終_修正.pptx` が最新であると回答される
- 最終更新日・更新者が根拠として明記される

### ナレーション
> ファイル名では判断できないものを、更新日という根拠つきで教えてくれます。
> 「最終」「最終_v2」「最終_修正」問題は、これで終わりです。

### 編集メモ
- 寸劇C4のセリフ（3つの紛らわしいファイル名）と対応していることを字幕で示す
- ファイル一覧の3ファイルを一度画面に映してから、Copilotの回答に切り替える

---

## 4. ステップ4: アジェンダと会議前ブリーフを作る（約45秒）

### 操作手順
1. 続けて質問する
2. 出力されたアジェンダをコピーし、**会議招待の本文またはTeamsチャットに貼り付ける**ところまで見せる

### 入力プロンプト
```
以上を踏まえて、今日14時からの「新サービス立ち上げ 定例」（60分）の
アジェンダを作ってください。条件は次のとおりです。
- 前回の持ち越し事項を最初に置く
- 各項目に想定時間を割り当て、合計を60分にする
- 各項目に「共有」「議論」「決定」のいずれかのラベルを付ける
- 最後に、私が会議前に目を通しておくべき資料を3点挙げる
```

### 期待される出力
- 時間配分つきのアジェンダ（合計60分）
- 各項目に 共有 / 議論 / 決定 のラベル
- 事前に読むべき資料3点

### ナレーション
> 5分でアジェンダができました。
> しかも「決定」のラベルが付いているので、この会議で何を決めるべきかが最初から共有されます。
> 空いた時間は、資料を探す時間ではなく、話す内容を考える時間に使えます。

### 編集メモ
- 「決定」ラベルの行だけを色付きで強調する
- 最後にアジェンダを会議招待へ貼り付けるカットを入れ、「実際に使える」ことを見せる
- 章の締めとして、寸劇C5の「会議まであと5分」の字幕を一瞬だけ重ねる（対比演出）

## 5. 収録チェックリスト

- [ ] 4ステップすべてが同一スレッドで完結している（会話の連続性）
- [ ] 実名・実データ・社外秘情報が1フレームも映っていない
- [ ] 出力に明らかな誤りがないか（誤りがある場合は再収録するか、ナレーションで補足する）
- [ ] マウスの動きが速すぎないか
- [ ] 各ステップの尺が目標±10秒に収まっているか

## 6. リスク対策（本番で出力が変わった場合）

- Copilotの出力は毎回同じにならない。**必ず事前に成功したテイクを録画で確保しておく**
- 出力が期待と異なる場合は、プロンプトに「形式」の指定を1行足して再実行する
- 会場でのライブデモは行わず、録画を再生する運用を推奨する

## 7. 補足ナレーション（任意・時間が余った場合）

> ここで使っているのは、特別な設定ではありません。
> ふだん自分がアクセスできる範囲の情報だけをAIが見ています。
> 権限のないファイルが出てくることはありません。
