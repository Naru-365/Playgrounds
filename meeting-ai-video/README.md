# その会議、AIに任せてみない？

会議と情報整理の効率化をテーマにした、**15分の社内向け紹介動画**の制作プロジェクト一式です。
「会議前・会議中・会議後」の3部構成で、生成AIによる寸劇（あるある）と、
実際の画面録画デモ（解決）を交互に見せる形式をとります。

- **総尺**: 15:00
- **言語**: 日本語（ja-JP）
- **対象**: 生成AI初学者 / Microsoft 365・Copilot利用者 / Teams会議を日常的に使う人
- **コアメッセージ**: 会議の面倒な情報整理をAIに渡せば、人は議論と意思決定に集中できる

---

## 全体構成

| 区間 | 時間 | 内容 |
|------|------|------|
| オープニング | 00:00–00:30 | タイトル / 3部構成の予告 |
| **第1章 会議前** | 00:30–05:00 | 寸劇75秒 + デモ167秒。テーマ「必要な情報が見つからない」 |
| **第2章 会議中** | 05:00–09:30 | 寸劇70秒 + デモ172秒。テーマ「メモに追われて議論に集中できない」 |
| **第3章 会議後** | 09:30–14:00 | 寸劇70秒 + デモ172秒。テーマ「終わっても情報整理が終わらない」 |
| クロージング | 14:00–15:00 | 振り返り / 明日から試せる3ステップ / 注意事項 |

各章は共通の型で進みます。

```
章タイトル(8s) → 寸劇（生成AI動画・悩みの提示） → 「これ、AIに任せられないかな」
  → 接続ナレーション(10s) → 画面録画デモ（実際の解決） → 章まとめ(10s)
```

## 制作の進め方

### ステップ1: 基準画像を作る（最初に必ずやる）

`prompts/characters.yaml` の `reference_image_prompt` を使って、次の4枚を生成します。

1. `employee_a.png` — サトウ（眼鏡 / ネイビーのカーディガン）
2. `employee_b.png` — タカハシ（眼鏡なし / ベージュのニット）
3. `open_office.png` — オープンオフィス（第1章・第3章）
4. `meeting_room.png` — 小会議室（第2章）

**この4枚が全カットの一貫性を決めます。** 妥協せず、納得のいくものができるまで作り直してください。

### ステップ2: カットを生成する

`prompts/gemini/*.yaml` の `prompt` をそのままコピーして入力し、
`reference_images` に書かれた基準画像を添付します。

- 1カットにつき **3〜5テイク** 生成する
- `split_hint` に「2ショットに分ける」とあるカットは、必ず分けて生成する
- `prompts/characters.yaml#consistency_checklist` で採用テイクを選ぶ
- 3回試しても一貫性が崩れる場合は、OTS・手元・引きの構図へ逃がす

### ステップ3: デモを収録する

`demo/*.md` の手順で画面録画します。**収録前に事前準備セクションを必ず消化してください。**

- 実データは録画しない（デモ専用テナント / ダミーデータのみ）
- 出力は毎回変わるため、**成功したテイクを必ず録画で確保する**（ライブデモは推奨しない）
- 第2章と第3章は同じ模擬会議のデータを使う（繋がりが説得力になる）

### ステップ4: 編集する

`editing/timeline.yaml` のタイムラインどおりに並べ、字幕・BGM・SEを乗せます。
最後に `final_check` のチェックリストを通します。

## 制作上の原則

| 原則 | 理由 |
|------|------|
| **製品UIは生成映像で再現しない** | 実際のUIは画面録画で見せる。生成映像内には読める文字を一切出さない |
| **登場人物の服装・髪型は3章通して不変** | 全体が「同じ1日の出来事」という設定。基準画像が唯一の正 |
| **寸劇の最後は必ず画面に寄って終わる** | 説明なしでデモへ切り替えるため。3章とも同じ型を使う |
| **決定事項・担当・期限は人が確認する** | AI出力をそのまま正解として扱わない。クロージングでも明示する |
| **演技は過剰にしない** | 「あるある」で頷かせる。笑わせにいかない |

---

## 変更するときは

- **尺を変える** → `project.yaml` の `overall_timeline` を直し、`editing/timeline.yaml` と各 `demo/*.md` の秒数を合わせる
- **セリフを変える** → `scripts/*.md` → `storyboards/*.yaml` → `prompts/gemini/*.yaml` の3か所すべてを更新する（同じセリフが3ファイルに存在します）
- **登場人物の見た目を変える** → `prompts/characters.yaml` を直し、基準画像を作り直し、全カットを再生成する（部分的な変更はできません）
